# Jack Mislinski

Software engineer and founder of [Aevox](https://aevox.health), AI analytics for metabolic testing deployed in five labs. I build AI software end to end and work forward-deployed: the first sales call, each lab's raw exports as they actually arrive, and the fix that ships the same week. Exercise physiologist (MSc Applied Physiology, UCCS), NYU Computer Science, three years building analytics and trading credit at Barclays.

**Aevox's code is private.** How it's built: [How Aevox reads a metabolic test](https://jackmislinski.com/aevox-architecture) covers ingest under physics checks, a deterministic threshold engine, a bounded model read, and a physiologist who confirms.
